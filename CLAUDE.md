# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Development Commands
- Develop: `npm run dev`
- Build: `npm run build`
- Start: `npm run start`

## Architecture
- Framework: Next.js 16 (App Router)
- Styling: Tailwind CSS 4
- Language: TypeScript
- Structure: Uses the `app/` directory for routing and layouts.

## Important Notes
- This project uses a version of Next.js with significant breaking changes compared to standard versions. Always refer to `AGENTS.md` and the local documentation in `node_modules/next/dist/docs/` for current API and conventions.
